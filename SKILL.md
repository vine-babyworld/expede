# Minhas Skills (Claude Code) — Projeto EXPEDE

Lista resumida de todas as skills disponíveis neste projeto, organizadas por origem.

## Nativas do Claude Code

| Skill | O que faz |
|---|---|
| verify | Testa se uma mudança funciona rodando o app |
| code-review | Revisa o diff atual (bugs e melhorias) |
| simplify | Simplifica/reduz código alterado |
| security-review | Revisão de segurança das mudanças pendentes |
| review | Revisa um pull request |
| init | Cria um CLAUDE.md inicial documentando o projeto |
| run | Sobe o app e mostra a mudança funcionando |
| loop | Repete um comando/skill em intervalos |
| schedule | Agenda execuções automáticas (cron) |
| fewer-permission-prompts | Reduz pedidos repetidos de permissão |
| update-config | Ajusta settings.json (hooks, permissões, env vars) |
| keybindings-help | Personaliza atalhos de teclado |
| claude-api | Referência da API Claude / Anthropic SDK |

## Plugin Superpowers (instalado neste projeto)

| Skill | O que faz |
|---|---|
| brainstorming | Refina a ideia antes de codar |
| writing-plans | Quebra o trabalho em tarefas pequenas e verificáveis |
| executing-plans | Executa o plano passo a passo |
| test-driven-development | Teste primeiro, código depois |
| systematic-debugging | Investiga causa raiz de bugs |
| requesting-code-review | Pede revisão de código ao terminar uma feature |
| receiving-code-review | Processa feedback de revisão recebido |
| verification-before-completion | Checklist final antes de marcar como pronto |
| using-git-worktrees | Trabalho isolado em feature sem bagunçar o resto |
| finishing-a-development-branch | Finaliza e limpa branch de feature |
| subagent-driven-development | Desenvolvimento orquestrado por subagentes |
| dispatching-parallel-agents | Dispara múltiplos agentes em paralelo |
| using-superpowers | Guia geral de uso do pacote Superpowers |
| writing-skills | Cria novas skills personalizadas |
